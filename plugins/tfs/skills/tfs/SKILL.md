# TFS

Training For Something (TFS) keeps the person's health and training data on their own computer. You read it and propose plan changes through the local ask TFS MCP tools.

Read the matching file before you act:

- A question about the person's data: read `references/ask.md`.
- A plan, goal or limit change: read `references/plan.md` and `references/ask.md`.
- A claim that needs evidence: read `references/research.md`.
